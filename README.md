🚀 What I'm building

F1 Virtual Pitwall V2 — an AI-powered Formula 1 race-strategy system that reconstructs historical races lap-by-lap without future-data leakage and models tyre, traffic, pit-window, and strategy decisions. Held-out 5-lap PIT MAE: 6.789s → 5.207s.

FinPulse — a financial research platform combining live portfolio analytics, SEC/news retrieval, hybrid RAG, specialist agents, and MCP tools.

GOCO AI — AI systems for a programming-learning and competitive-coding platform, including learner modelling, coding workflows, JavaCC compiler integration, and contest-safe assistance.

I also explore local LLMs, reinforcement learning, agent evaluation, financial ML, and applied AI systems.
