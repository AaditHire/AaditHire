### About

- 📈 &nbsp; Developing **[FinPulse](https://github.com/AaditHire/FinPulse)** for portfolio analytics and evidence-backed financial research.

### Featured projects

> 🏎️ **[F1 Virtual Pitwall V2](https://github.com/AaditHire/f1-virtual-pitwall-V2)** — an AI-powered Formula 1 race-strategy system that reconstructs historical races lap-by-lap without future-data leakage and models tyre, traffic, and pit decisions. **Held-out 5-lap PIT MAE: 6.789s → 5.207s.**<br/>
> `Python · FastAPI · FastF1 · Pydantic`

> 📊 **[FinPulse](https://github.com/AaditHire/FinPulse)** — a financial research platform combining portfolio analytics, SEC/news retrieval, RAG, specialist agents, and MCP tools.<br/>
> `Next.js · Python · Supabase · pgvector · MCP`

> 💻 **GOCO AI** — AI systems for a programming-learning and competitive-coding platform, including learner modelling, coding workflows, and contest-safe assistance.<br/>
> `FastAPI · JavaCC · SQLite · Ollama · Qwen`
